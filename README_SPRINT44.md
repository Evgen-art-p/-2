## ЗАКОН ДВУХ ВАЛЮТ (текст для STUDIO_CONTEXT)

Шкала одна — 0–10. Источников два:

**CHAIN-валюта (0–6.0) — ремесло.** Детерминированная оценка цепочки после QA.
Потолок 6.0 = «выжил, сделал по ТЗ, чисто». Успех = чистая 6.0, провал < 4.0.
Кормит: лёгкие мутации DNA (good_work 0.7 / 0.35 / bad_work), режимы
frugal/normal, серии и звёзды agent_feedback, chain-wins в Strategy Registry.
Писатель Ministry — **только pipeline** после QA (source="chain"), per-agent
оценки из feedback.json, стоимость = **дельта расходов рана**.

**REAL-валюта (0–10) — зритель.** Реальные метрики после публикации или живой
QA Шефа. Успех ≥ 7.0, провал < 5.0. **Единственный источник режима generous**,
transferable-стратегий и оценок выше 6.0. Писатель — **только Metrics Daemon**
(source="real", честные ключи Axx::slot).

**Интуиция = ROI.** Ощущение агента строится из пары (стоимость, качество из
task_score), а не из одной стоимости — как требовала исходная спека ЭТАПА 2
(outcome_quality) и «ROI Резонанса» из Глубинного анализа.

**Reward > Punishment.** Generous открывает только зритель; frugal-хинт говорит
про экономику путей, не про «слабость» агента. Скрипт девятки не чеканит.
