## ЧАСТЬ 2 — БАГИ И НЕСООТВЕТСТВИЯ

### 🟢 ЗАКРЫТО В СПРИНТЕ 15:

**[ЗАКРЫТ] conflict_mode не читался из manifest.json**
- Поле `conflict_mode` было в JSON каждого манифеста, но не было в датаклассе `CartridgeManifest`
- `hasattr(self.manifest, 'conflict_mode')` → всегда `False` → конфликты никогда не запускались
- Фикс: добавлены `conflict_mode: str = "none"` в датакласс и `conflict_mode=data.get(...)` в `load()`
- Все 11 манифестов уже имеют `"conflict_mode": "divergent"` → конфликты оживут после перезапуска

**[ЗАКРЫТ] QA-агент хардкодом "A12" — не работал в кастомных цехах**
- Turbo (A01–A05), cоцсети, кастомные цеха без A12 → петля feedback никогда не замыкалась
- Фикс: `_qa_agent = последний агент цеха` если qa_agent из манифеста не входит в пайплайн
- Теперь любой цех любой комплектации получает QA-агента автоматически

**[ЗАКРЫТ] save_feedback() понимала только формат A12 (blocks)**
- Агенты A16 (otk_checklist), A05 и любые другие не-A12 QA → данные не писались
- Фикс: добавлен `_extract_score()` — универсальный парсер (blocks / otk_checklist / status / прямой score)
- Фикс: добавлен параметр `agent_ids` — при отсутствии blocks score распределяется по всем агентам рана

**[ЗАКРЫТ] record_strategy вызывался с захардкоженным score=7.0**
- Каждый агент сразу после рана записывал стратегию с оценкой 7.0 (ниже порога 8.0)
- Strategy Registry оставался пустым несмотря на корректный код фильтрации
- Фикс: ранний вызов убран. Стратегии пишутся только через `_record_winning_strategies()` после QA

**[ЗАКРЫТ] culture/field_tracker.py не был подключён**
- 22KB готового кода Этапа 8 висели мёртвым грузом
- Фикс: вызов `CulturalFieldTracker().update_slot_field(slot_id)` добавлен в `cartridge.py` после каждого рана
