## ПРАВИЛА ИСПОЛЬЗОВАНИЯ

1. **ref_ids** — список ID ассетов для каждого кадра/обложки
2. Персонажи (`char_*`) → reference для лица и одежды
3. Локации (`loc_*`) → reference для фона/среды
4. Реквизит (`prop_*`) → reference для предметов
5. Один кадр может содержать несколько ref_ids: `["char_ashota", "loc_kafe"]`
6. Если подходящего ассета нет — НЕ УКАЗЫВАЙ ref_ids, промпт будет текстовый
7. Assembly Line автоматически подставит изображения ассетов при генерации
