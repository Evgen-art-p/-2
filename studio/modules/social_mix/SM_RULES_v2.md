## 5. history_dna и оценка качества

- **Создаёт:** Костя (01) — `project_id`, `mode`, `run_type`, `platform`
- **Наследуют:** Все агенты через `{{inherit}}`
- **Финализирует Клавдия (12):** `status: "PENDING"`, `post_id: null`, `tim_forecast`
- **Финализирует Metrics Daemon (через 24ч):** `real_viral_score`, `forecast_delta`, `learnings`, `avoid_next`

**Важно:** Клавдия НЕ вызывает `ministry.record_outcome`.
Ministry обновляет **исключительно Metrics Daemon** — только с реальными данными.

## 8. КЛЮЧЕВЫЕ ПРАВИЛА

- **Hook = первые 2-3 секунды / слова** — без него пост мёртв
- **Один пост = один конфликт** (Макс)
- **CTA ≠ "лайк/подписка"** — провокация, вопрос, вызов (Белла)
- **viral_score Тима = гипотеза**, не оценка. Metrics Daemon сравнит с реальностью через 24ч
- **Негативный промпт обязателен если risk > 30%** (Федя)
- **Платформа определяет адаптацию** — IG/VK/TG/universal
- **KB-гайды по платформам** у каждого агента
- **ministry.record_outcome** вызывает только Metrics Daemon — не агенты, не hooks.py

## 9. АСИНХРОННАЯ ПЕТЛЯ ОБРАТНОЙ СВЯЗИ

Клавдия закрывает пайплайн со статусом `PENDING`. Дальше работают два независимых узла:

```
Пайплайн завершён → claudia_final: status=PENDING, tim_forecast=X
        ↓
  [Сборочный цех — Assembly]
  Broadcaster (studio/assembly/broadcaster.py)
  Кнопка 📤 в pub_panel → читает токены из clients/{client_id}/social_config.json
  → публикует пост → сохраняет post_id в clients/{client_id}/pending_posts.json
        ↓
  [Фоновый демон — Economy]
  Metrics Daemon (studio/economy/metrics_daemon.py)
  Каждый час проверяет все clients/*/pending_posts.json
  Посты старше 24ч → забирает метрики из API → считает real_viral_score
  → ministry.record_outcome() → обновляет final_dna → status=scored
        ↓
  forecast_delta = real_viral_score − tim_forecast
  Агенты умнеют по реальным данным живых людей
```

**Credentials:** токены и channel_id живут в `clients/{client_id}/social_config.json`.
Никакого ввода токенов в интерфейсе. Никаких .env.
**UI (pub_panel):** только кнопка и индикатор статуса — глупый пульт.
