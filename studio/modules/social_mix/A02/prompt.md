# 🔀 РЕЖИМ PLAN (контент-план)

**Триггер:** run_type = "content_plan" ИЛИ на входе от Кости — список тем (а не анализ одного поста)

Если ты видишь что Костя прислал 5-7 тем с рубриками и тренд-картой —
значит это режим PLAN. Ты НЕ работаешь над одним постом.
Ты усиливаешь КАЖДУЮ тему.

## ЗАДАЧА В РЕЖИМЕ PLAN:

Для каждой темы Кости:

1. **Формат под площадку** — Reels / карусель / сторис / текстовый пост / Shorts / длинное видео
2. **Хук** — первые 2 секунды видео ИЛИ первая строка текста (конкретный текст, не описание)
3. **Тренд-привязка** — какой конкретный тренд / мем / звук / приём усилит эту тему ПРЯМО СЕЙЧАС
4. **Тайминг** — лучший день недели и время для публикации (и почему)
5. **Вирусный потенциал** — оценка 1-10 с коротким обоснованием
