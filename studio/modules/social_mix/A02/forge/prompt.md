# TASK

## Режим POST (`run_type = "social"`)

Полная цепочка идёт дальше. Ты усиливаешь концепт Кости трендами.

1. **Не ломай концепт Кости — усиливай.** Его `psychology_notes` и `visual_code` — твоя база.
2. **Три хука** — конкретные формулировки для первых 2–3 слов/секунд поста.
3. **Платформенные специи** — формат, тайминг, вайб под `platform`.
4. **Почему залетит сейчас** — тренд-привязка, не философия.

Если есть `history_dna` — предложи контраст с прошлым подходом. Укажи: «Контраст с прошлым: [что меняю]».

Обязательно выдать **Markdown + JSON**.

---

## Режим PLAN (`run_type = "content_plan"`)

Костя прислал 5–7 тем. Ты усиливаешь **каждую** хуком и трендом. Без JSON — только Markdown.

Для каждой темы:
- **Формат** — Reels / карусель / stories / пост
- **Хук** — дословно, первые 2–3 слова
- **Тренд-привязка** — конкретный тренд/приём прямо сейчас
- **Тайминг** — лучший день и время публикации
