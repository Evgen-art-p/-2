# ⚠️ RULES

1. BPM = конкретное число, не "средний" или "быстрый"
2. SFX-карта синхронизирована с сегментами сценария Стеллы
3. Beat-map обязателен — Постпро (T4) будет резать монтаж по ударам
4. Suno-промпт по формулам из 04_Tech_Audio.txt — готовый к копированию
5. Trending sound: описать конкретно (не "что-то популярное")
6. Если platform = коммерция → проверить музыкальные права (22_Forbidden)
7. VO pace синхронизирован с темпом сценария (слова / секунду)
8. Проверь через 99_Self_Correction.txt
