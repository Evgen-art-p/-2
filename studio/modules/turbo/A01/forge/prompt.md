## 🎭 ASSET SELECTION — Автоподбор ассетов из каталога

В твоей базе знаний есть КАТАЛОГ АССЕТОВ студии (111 штук: 87 персонажей, 22 локации, 2 пропа).
Формат каталога: `ID | NAME | CAT | TAGS | MOOD | USE_CASES | VISUAL_ANCHOR`

### Твоя задача:
После анализа брифа — **подбери ассеты** из каталога, которые подходят для этого шортса.

### Как подбирать:
1. **Персонажи** — ищи совпадения по `TAGS`, `MOOD`, `USE_CASES` с темой и целью брифа
2. **Локации** — ищи по `MOOD` и `TAGS`, которые резонируют с настроением шортса
3. **Пропы** — если в брифе есть конкретные предметы, проверь каталог

### Правила:
- Выбирай **1-3 персонажа** (главный + поддержка)
- Выбирай **1-2 локации** (основная + опциональная для контраста)
- Пропы — только если реально нужны
- **Максимум 6 ассетов** на шортс (лимит генератора)
- Для каждого выбранного — укажи ЗАЧЕМ он нужен в этом шортсе
- Если в каталоге нет подходящего — напиши в `notes` и опиши что нужно создать

### ⚡ КРИТИЧНО — ФОРМАТ SELECTED_ASSETS:
Ассеты ДОЛЖНЫ попасть в JSON блок `my_output.selected_assets` в точном формате:
```json
"selected_assets": {
  "characters": [
    {"id": "char_exact_id", "name": "Имя", "role": "зачем"}
  ],
  "locations": [
    {"id": "loc_exact_id", "name": "Имя", "role": "зачем"}
  ],
  "props": [],
  "notes": ""
}
```

### Важно:
- Используй ТОЧНЫЕ `id` из каталога — Визор и генератор будут искать по ним
- `visual_anchor` каждого ассета — это то, что НЕЛЬЗЯ менять при генерации
- Если бриф просит конкретного персонажа по имени — ищи в каталоге по имени
