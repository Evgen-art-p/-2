## 0. Зачем этот закон и почему он трудный

Этой системой почти никто не торгует — **не умеют**. Здесь не голая
математика, которую обскачет любой индикатор. Здесь **чтение волны +
психология толпы + характер трейдера** в одном узле. Её нельзя свести к
«если RSI < 30 — покупай». Её надо **понимать**.

Мы строим то, что понимает. Этот документ — фундамент: карта, по которой
режется `hooks.py` и пишутся промты трёх трейдеров.

Старая модель кода мыслила **баром**: один `trade_setup` на бар, трое читают
синхронно, хард-стоп если все отказали. Это неверно. Рынок — **волна, текущая
во времени**, фрактальная, как матрёшка. Этот закон описывает верную модель.

---

## 1. Четыре опоры

1. **Сессия дежурства** — единица работы цеха. Не бар. От первого удара до
   закрытия последней позиции. Внутри — дежурство бар за баром.
2. **Сенсор-свидетель** — бьёт по своей сигнатуре, когда видит своё.
   Не советует, не считает вход. Сканирует параллельно с другими.
3. **Фрактальность + якорь** — сигналы рождаются на разворотах ЛЮБОЙ степени;
   чтобы не утонуть в матрёшке, вбит канон якоря (глобальный/рабочий/младший).
4. **Трое по тренду** — Авантюрист, Брут, Консерватор. Все входят ПО тренду,
   разница — порог доверия к тому, что коррекция кончилась и тренд продолжается.

---

## 2. Канон якоря — три таймфрейма (опора против бесконечной матрёшки)

Матрёшка бесконечна вверх и вниз. «Разворот чего?» не имеет ответа без якоря.
Поэтому — три гвоздя, между которыми работаем:

```
ГЛОБАЛЬНЫЙ (на ступень старше рабочего, ×5) ─► НАПРАВЛЕНИЕ
        напр. рабочий H4 → глобальный W1 (неделя)
              рабочий D1 → глобальный MN1 (месяц)
        Задаёт главный тренд. Коррекцию глобального НЕ ТОРГУЕМ — ждём.
        Не сидим в рынке годами — берём импульсы своего масштаба.
        │
РАБОЧИЙ (где видим ситуацию) ─────────────► СОБЫТИЕ / ДЕЖУРСТВО
        Здесь сенсоры бьют. Здесь трейдер входит и ведёт позицию.
        │
МЛАДШИЙ (лесенка вниз, _descend) ─────────► ТОЧНОСТЬ
        Спуск на младшие ТФ, чтобы:
          а) уточнить РАЗВОРОТНЫЙ БАР (на рабочем размазан, ниже — чёткий)
          б) довести окно осциллятора до 100–140 баров (фокус, вера AO)
```

**ТФ — не настройка цеха, а часть самой ситуации.** Связь «рабочий+глобальный»
не зашита в конфиг. Есть рынок, есть ситуация — интересно, работаем. Цех
**опознаёт** ситуацию, а не сверяется с галочкой настроек. Даже выбор ТФ —
это чтение рынка.

🆕 **КОМПАС ДВУХКОНТУРНЫЙ (приведено к коду v1.2).** Глобальное направление
теперь добывается двумя путями: (1) дивер-компас спуска (`_compass_from` —
точный, редкий) и (2) фоллбэк `global_bias` из СИНЕЙ линии Аллигатора (Jaw,
SMMA-13 — самый инертный баланс = дыхание старшего ТФ в рабочем окне, считает
ядро). ⚠️ Сейчас синяя питает `trend_direction`, но НЕ сам спуск — оттого спуск
находит редко. Открытый долг: подключить синюю к спуску (см. карту статуса).

## 3. Карта волны — порядок рождения сигналов (по течению, не по нашему вкусу)

Глобальный тренд **вверх**. На рабочем ТФ идёт откат A-B-C вниз (коррекция).

```
ГЛОБАЛЬНЫЙ тренд ВВЕРХ (неделя)
   │
   └─ на рабочем ТФ: откат A-B-C вниз = коррекция глобального
        │
        │   ⏸  ЦЕХ ЖДЁТ. Коррекцию не торгуем. Сидим на руках.
        │
        ├─ конец волны C = РАЗВОРОТ ВВЕРХ (продолжение глобального тренда!)
        │     ИСКРА бьёт: дивергенция AO на дне C, Точка Ноль
        │     ─► АГРЕССИВНЫЙ сигнал ─► АВАНТЮРИСТ заходит (самый ранний)
        │
        ├─ пошла волна 1 нового импульса вверх
        │
        ├─ на макушке импульса рисуется ФРАКТАЛ за пастью
        │     ГАНС бьёт: пробой фрактала выше Teeth
        │     ─► БРУТ ставит ордер (канон §6.1, ждал подтверждения)
        │     Авантюрист тем временем может ДОЛИВАТЬ пирамиду
        │
        ├─ откат волны 2: разрядка AO к нулю, опора (пасть / уровень в.4)
        │     ─► сигнал КОНСЕРВАТОРУ (§6.3, надёжнейший вход на опоре)
        │
        ├─ волна 3 — разгон. Тренд держит весь АЛЛИГАТОР (три линии открыты).
        │     МОРЖ не «держит тренд» — он сторож НАТЯЖЕНИЯ РЕЗИНКИ. Звенит
        │     на изломе: острый откат волны 2 и ИЗЛЁТ волны 3/5.
        │     Пирамида доливок по каждому новому пробитому фракталу.
        │     ... до следующего разворота (дивер на вершине) = выход всем объёмом.
```

**Зеркально для тренда вниз.**

## 4. Фрактальность — сенсоры бьют на развороте ЛЮБОЙ степени

Базовый цикл Эллиотта 5-3 повторяется на всех масштабах. Каждая волна состоит
из восьми (5+3), и каждая из восьми — снова из восьми. Матрёшка.

- **Искра ловит конец волны C любого отката** — конец C = разворот = рождение
  нового импульса этой степени.
- **Сенсор не знает «номер волны».** Знает свою сигнатуру и бьёт, когда видит
  её на свече — на любой степени. Якорь (§2) задаёт главную степень.

Индивидуальность волн (Эллиотт §6) — подписи сенсоров:
- **Излёт волны 3/5:** расхождение + резинка на пределе → ИСКРА + МОРЖ
- **Волна 3 (тело):** прорыв, объёмы → ГАНС (фрактал за пастью)
- **Конец волны C:** разворот в сторону тренда → ИСКРА (дивер на дне C)
- **Тренд жив или нет** — это весь АЛЛИГАТОР, не Морж.

**Затвор Моржа (MORJ_MATH §3).** Натяжение резинки копится долго и само по себе
НЕ событие. Триггер фиксации — **сигнал Искры**. В момент удара Искры Морж
делает срез: резинка на пике (`is_peak`)? Да → ангуляция истинная
(`tension_peak=true`). Две лампочки раздельно: пасть (`wave_1_validated`) и
резинка (`tension_peak`) — независимы.

## 5. Сессия дежурства и удар

- **Первый удар открывает сессию.** Чаще Искра на развороте C. С этого мига
  цех на ногах.
- **Трое не спят до закрытия последней позиции.**
- **Дежурство — бар за баром.** Каждая свеча = новая ситуация на всех степенях.
- **Удар = вводная по сигналу.** Сенсор стучит, когда увидел СВОЁ.
- **Сканирование параллельное.** Очереди «сначала Искра, потом Морж» — нет.

🆕 **ВОРОТА СОВЕТА (приведено к коду v1.2).** Минимальное условие, при котором
цех будит Совет — **факт спуска Искры** (`descent.found`), а НЕ суждение
Искры-LLM (`t1_status`). Спуск нашёл точку → весь Совет садится и решает сам.
Искра кричит «вижу!», судят все вместе — один часовой не глушит круг своим
настроением. `t1_status` остался ГОЛОСОМ Искры (мнение в Совет), не затвором.
⚠️ Спуск находит редко (см. §2, открытый долг компаса).

## 6. Сенсор — свидетель, не советчик (смерть `_prepare_trade_setup`) ✅ СДЕЛАНО

- Сенсор **не считает вход**. Не говорит direction. Не кладёт entry/stop.
- Сенсор подаёт голос только при свидетельстве: «вот что вижу сейчас».
- Код бьёт в колокол и кладёт **показание + раскладку момента** (§8). Решать — трейдеру.

✅ В коде: `trade_setup` мёртв (CHAIN_CONTRACT §11). Трейдеры (brut/avan/cons)
считают `*_direction/*_entry/*_stop` сами из раскладки. Сенсоры кладут факты.

Цель: **научить трейдера читать рынок самому.** Сенсоры — удары, колокола.
Смотреть, понимать, решать — учится трейдер.

## 7. Трое по тренду — три порога доверия к продолжению ✅ СДЕЛАНО

Спор про контртренд закрыт: **никто не торгует против глобального тренда.**
Все трое входят в ПРОДОЛЖЕНИЕ тренда, разница — насколько рано каждый верит,
что коррекция кончилась.

| **Авантюрист** | A07 | §6.2 — РБ, Уровень 5 «Эксперт» | конец волны C, ТОЛЬКО при пяти пулях | верит первым. Ловец ножей |
| **Брут** | A06 | §6.1 — пробой фрактала за пастью | макушка импульса волны 1 | книга сказала — вошёл |
| **Консерватор** | A08 | §6.3 — РБ на откате волны 2 | откат + разрядка AO, опора | позже всех, надёжнее всех |

✅ В коде: brut_live/avan_live/cons_live — живые близнецы, свои промты/пороги/дневники.

**Пять волшебных пуль Авантюриста (Уровень 5).** Входит на развороте C ТОЛЬКО

## 8. Раскладка момента — что код кладёт трейдеру на удар ✅ СДЕЛАНО (+ обогащена)

Трейдер (LLM) просыпается на вызов, видит контекст, решает, засыпает. Код-глаза
кладут ему **готовую раскладку**, посчитанную ядром:

```
УДАР Ганса. Трейдеру на стол:
  · ЯКОРЬ: глобальный тренд (компас) — лонги/шорты разрешены
  · ЛЕСЕНКА ТФ: рабочий + спуск (волна растянута, AO верить)
  · ИНДИКАТОРЫ: AO, AC, MFI, фрактал, Teeth
  · ХОЗЯИН БАРА (OHLC): где закрытие
  · ЛЕНТА СЕССИИ: удары по барам
  · ТВОЙ ДНЕВНИК: личный опыт на такие удары
  · НА ПОЛКЕ: канон волны + книжки сенсоров
  🆕 · ТВОЯ ПОЗИЦИЯ (position): если ты в рынке — direction/entry/stop/lot/
       floating_r/bars_alive. Нет позиции → null. (TRADER_SEES_POSITION_V1)
  🆕 · global_bias: компас из синей линии (BULL/BEAR/NONE), всегда на столе
```

Трейдер **не считает — читает раскладку и судит характером.**

## 9. Три слоя знания трейдера (учить читать рынок самому)

**Слой 1 — КАНОН ВОЛНЫ (общий).** «Единая система» + «Эллиотт». Где я на карте.

**Слой 2 — КНИЖКИ СЕНСОРОВ (общие, читаются характером).** MORJ_MATH,
PANIKYOR_MATH, WILLIAMS_MATH, книга Ганса. Трейдер понимает удар со смыслом и
видит, как сенсоры складываются в одно показание волны (их ансамбль).

> Одна книга — три прочтения. Из общего канона через разный характер рождается
> **вой** — свой голос у каждого.

**Слой 3 — ЛИЧНЫЙ ДНЕВНИК (только свой).** Вводная → как поступил → что вышло.
Разные дневники у троих. Архивариус только раздаёт. Опыт живёт в руках трейдера.

```
Слой 1: КАНОН ВОЛНЫ      → где я на карте (общий)
Слой 2: КНИЖКИ СЕНСОРОВ  → что говорят свидетели и как складываются (общий)
Слой 3: ЛИЧНЫЙ ДНЕВНИК   → мой опыт (только свой)
        └─ всё через характер = ВОЙ (свой голос)
```
