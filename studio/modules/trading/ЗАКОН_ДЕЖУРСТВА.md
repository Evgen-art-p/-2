## 0. Зачем этот закон и почему он трудный

Этой системой почти никто не торгует — **не умеют**. Здесь не голая
математика, которую обскачет любой индикатор. Здесь **чтение волны +
психология толпы + характер трейдера** в одном узле. Её нельзя свести к
«если RSI < 30 — покупай». Её надо **понимать**.

Мы строим то, что понимает. Этот документ — фундамент: карта, по которой
потом режется `hooks.py` и пишутся промты трёх трейдеров. До этого код не
трогаем. Сначала — закон.

Старая модель кода мыслила **баром**: один `trade_setup` на бар, трое читают
синхронно, хард-стоп если все отказали. Это неверно. Рынок — **волна, текущая
во времени**, фрактальная, как матрёшка. Этот закон описывает верную модель.

---

## 1. Четыре опоры

1. **Сессия дежурства** — единица работы цеха. Не бар. От первого удара до
   закрытия последней позиции. Внутри — дежурство бар за баром.
2. **Сенсор-свидетель** — бьёт по своей сигнатуре, когда видит своё.
   Не советует, не считает вход. Сканирует параллельно с другими.
3. **Фрактальность + якорь** — сигналы рождаются на разворотах ЛЮБОЙ степени;
   чтобы не утонуть в матрёшке, вбит канон якоря (глобальный/рабочий/младший).
4. **Трое по тренду** — Авантюрист, Брут, Консерватор. Все входят ПО тренду,
   разница — порог доверия к тому, что коррекция кончилась и тренд продолжается.

## 2. Канон якоря — три таймфрейма (опора против бесконечной матрёшки)

Матрёшка бесконечна вверх и вниз. «Разворот чего?» не имеет ответа без якоря.
Поэтому — три гвоздя, между которыми работаем:

```
ГЛОБАЛЬНЫЙ (на ступень старше рабочего, ×5) ─► НАПРАВЛЕНИЕ
        напр. рабочий H4 → глобальный W1 (неделя)
              рабочий D1 → глобальный MN1 (месяц)
        Задаёт главный тренд. Коррекцию глобального НЕ ТОРГУЕМ — ждём.
        Не сидим в рынке годами — берём импульсы своего масштаба.
        │
РАБОЧИЙ (где видим ситуацию) ─────────────► СОБЫТИЕ / ДЕЖУРСТВО
        Здесь сенсоры бьют. Здесь трейдер входит и ведёт позицию.
        │
МЛАДШИЙ (лесенка вниз, _descend) ─────────► ТОЧНОСТЬ
        Спуск на младшие ТФ, чтобы:
          а) уточнить РАЗВОРОТНЫЙ БАР (на рабочем размазан, ниже — чёткий)
          б) довести окно осциллятора до 100–140 баров (фокус, вера AO)
```

**ТФ — не настройка цеха, а часть самой ситуации.** Связь «рабочий+глобальный»
не зашита в конфиг. Есть рынок, есть ситуация — интересно, работаем. Цех
**опознаёт** ситуацию (вот тут на рабочем зреет разворот под глобальный тренд),
а не сверяется с галочкой настроек. Даже выбор ТФ — это чтение рынка.

## 3. Карта волны — порядок рождения сигналов (по течению, не по нашему вкусу)

Глобальный тренд **вверх**. На рабочем ТФ идёт откат A-B-C вниз (коррекция).

```
ГЛОБАЛЬНЫЙ тренд ВВЕРХ (неделя)
   │
   └─ на рабочем ТФ: откат A-B-C вниз = коррекция глобального
        │
        │   ⏸  ЦЕХ ЖДЁТ. Коррекцию не торгуем. Сидим на руках.
        │
        ├─ конец волны C = РАЗВОРОТ ВВЕРХ (продолжение глобального тренда!)
        │     ИСКРА бьёт: дивергенция AO на дне C, Точка Ноль
        │     ─► АГРЕССИВНЫЙ сигнал ─► АВАНТЮРИСТ заходит (самый ранний)
        │
        ├─ пошла волна 1 нового импульса вверх
        │
        ├─ на макушке импульса рисуется ФРАКТАЛ за пастью
        │     ГАНС бьёт: пробой фрактала выше Teeth
        │     ─► БРУТ ставит ордер (канон §6.1, ждал подтверждения)
        │     Авантюрист тем временем может ДОЛИВАТЬ пирамиду
        │
        ├─ откат волны 2: разрядка AO к нулю, опора (пасть / уровень в.4)
        │     ─► сигнал КОНСЕРВАТОРУ (§6.3, надёжнейший вход на опоре)
        │
        ├─ волна 3 — разгон. Тренд держит весь АЛЛИГАТОР (три линии открыты).
        │     МОРЖ не «держит тренд» — он сторож НАТЯЖЕНИЯ РЕЗИНКИ. Звенит
        │     на изломе: острый откат волны 2 (натяжение перед отскоком) и
        │     ИЗЛЁТ волны 3/5 (резинка на пределе — предвестник выдоха).
        │     Пирамида доливок по каждому новому пробитому фракталу.
        │     ... до следующего разворота (дивер на вершине) = выход всем объёмом.
```

**Зеркально для тренда вниз.** Всё то же, отражённое: конец волны C отката
вверх = разворот вниз = продолжение нисходящего тренда.

## 4. Фрактальность — сенсоры бьют на развороте ЛЮБОЙ степени

Базовый цикл Эллиотта 5-3 повторяется на всех масштабах (§1.1 паспорта
Эллиотта: «форма постоянна для всех временных масштабов»). Каждая волна
состоит из восьми (5+3), и каждая из восьми — снова из восьми. Матрёшка.

Поэтому:
- **Искра ловит конец волны C любого отката** — даже на рабочем ТФ, считая
  разворот отката. Конец C = разворот = рождение нового импульса этой степени.
- Внутри волны 1 есть свои 1-2-3-4-5; на дне её волны 2 — снова разворот,
  снова дивер, снова Искра, степенью ниже.
- **Сенсор не знает «номер волны».** Он знает свою сигнатуру и бьёт, когда
  видит её на свече — на любой степени. Якорь (§2) задаёт, какую степень
  считаем главной, чтобы не захлебнуться в микроскладках.

Индивидуальность волн (Эллиотт §6) — это и есть подписи сенсоров:
- **Излёт волны 3/5:** расхождение с индикаторами + резинка на пределе →
  ИСКРА (дивер, затвор) + МОРЖ (срез натяжения на этом затворе)
- **Волна 3 (тело):** прорыв, объёмы, признание тренда → ГАНС (фрактал за пастью)
- **Конец волны C:** разворот в сторону тренда → ИСКРА (дивер на дне C)
- **Тренд жив или нет** — это весь АЛЛИГАТОР (пасть открыта/спит), не Морж.

**Затвор Моржа (по эталонной MORJ_MATH §3).** Натяжение резинки (пустота
Lips↔экстремум) копится долго и само по себе НЕ событие. Триггер фиксации —
**сигнал Искры** (дивергентный бар). В момент удара Искры Морж делает срез:
резинка на пике прямо сейчас (`is_peak`)? Да → ангуляция ИСТИННАЯ, возвратный
удар созрел (`tension_peak=true`). Нет → рано. **Ангуляция обретает смысл
только в связке с разворотным сигналом** — Морж не звенит сам по себе.
Две лампочки раздельно: пасть (тренд жив, `wave_1_validated`) и резинка
(натяжение, `tension_peak`) — независимы, не смешивать.

## 5. Сессия дежурства и удар

- **Первый удар открывает сессию.** Чаще это Искра на развороте C (самый
  ранний сигнал), но открыть может любой первый удар. С этого мига цех на ногах.
- **Трое не спят до закрытия последней позиции.**
- **Дежурство — бар за баром.** Каждая свеча = новая ситуация на всех степенях
  матрёшки сразу: может быть концом микро-отката (разворот!), горбом с фракталом,
  началом ангуляции. Пропустишь свечу — пропустишь разворот матрёшки.
- **Удар = вводная по сигналу.** Сенсор стучит не по расписанию каждый бар, а
  когда увидел СВОЁ. «Я, Ганс, вижу фрактал за пастью на 1.0840». Показание
  свидетеля, не анкета всех полей.
- **Сканирование параллельное.** Все четыре сенсора смотрят каждую свечу
  независимо. Порядок появления ударов задаёт сама волна (разворот → ангуляция
  → фрактал → откат), а не код. Очереди «сначала Искра, потом Морж» — нет.

## 6. Сенсор — свидетель, не советчик (смерть `_prepare_trade_setup`)

- Сенсор **не считает вход**. Не говорит direction. Не кладёт entry/stop.
- Сенсор подаёт голос только при свидетельстве: «вот что вижу сейчас».
- Код бьёт в колокол и кладёт **показание + раскладку момента** (см. §8).
  Решать — трейдеру.

Цель, к которой идём: **научить трейдера читать рынок самому.** Сенсоры —
удары, раздражители, колокола. Смотреть, понимать, решать — учится трейдер.

## 7. Трое по тренду — три порога доверия к продолжению

Спор про контртренд закрыт: **никто не торгует против глобального тренда.**
Авантюрист не дурак — на развороте глобальной 5-й (начало коррекции) он НЕ
входит, цех ждёт. Все трое входят в ПРОДОЛЖЕНИЕ тренда, разница — насколько
рано каждый верит, что коррекция кончилась.

| Трейдер | ID | Модуль | Станция | Порог доверия |
|---|---|---|---|---|
| **Авантюрист** | A07 | §6.2 — Разворотный Бар, **Уровень 5 «Эксперт»** | конец волны C отката, но ТОЛЬКО при пяти пулях | верит первым. Входит не на любом конце C, а лишь когда сошлись **5 волшебных пуль** (см. ниже). Ловец падающих ножей — жёсткий риск-модуль |
| **Брут** | A06 | §6.1 — пробой фрактала за пастью | макушка импульса волны 1 | ждёт подтверждения структурой. Книга сказала — вошёл. Канон Котина |
| **Консерватор** | A08 | §6.3 — РБ на откате волны 2 | откат + разрядка AO к нулю, опора | ждёт ещё и отката волны 2. Позже всех, надёжнее всех |

Один и тот же разворот C → три реакции. Авантюрист уже в рынке и доливает.
Брут ждёт фрактал. Консерватор сверился — рано, ждёт опору. Это **три точки
одной истории**, не три мнения об одном баре.

**Пять волшебных пуль Авантюриста (Уровень 5, по сверке Локи).** Торговля
самой Точки Ноль — высший и опаснейший уровень Вильямса. Для новичка это
ересь и слив. Авантюрист входит на развороте C ТОЛЬКО когда сошлись все пять:
1. дивергенция AO (сигнал Искры);
2. целевая зона (Фибо/канал — где коррекция обязана кончиться);
3. фрактал на дне отката;
4. приседающий бар (Squat: +объём, −MFI);
5. смена моментума (AO разворачивается).
Меньше пяти — пас. Риск-модуль ловца ножей: **меньший стартовый объём,
ближний стоп за хвост РБ** — если C сделает ещё ногу вниз, выбьет дёшево.

**Хард-стоп «все трое отказали» — ошибка модели, подлежит сносу.** Они и
ДОЛЖНЫ почти всегда молчать — каждый ждёт свою станцию. «Все отказали» по
удару = норма, не повод глушить дежурство.

## 8. Раскладка момента — что код кладёт трейдеру на удар

Трейдер (LLM) не калькулятор и не сидит у графика. Он просыпается на вызов,
видит контекст, решает, засыпает. Поэтому код-глаза (которые мониторят бар за
баром и не спят) кладут ему **готовую раскладку**, посчитанную ядром:

```
УДАР Ганса. Трейдеру на стол:
  · ЯКОРЬ: глобальный W1 — тренд ВВЕРХ (лонги разрешены)
  · ЛЕСЕНКА ТФ: рабочий H4 — Аллигатор открыт вверх, цена вне пасти;
    спуск M15 — волна растянута на 118 баров (фокус идеален, AO верить)
  · ИНДИКАТОРЫ (рабочий ТФ): AO растёт, AC растёт, MFI=Fade,
    фрактал вверх 1.0840 (выше Teeth 1.0815)
  · ХОЗЯИН БАРА (OHLC): закрытие в верхней трети — быки держат
  · AIR BAG: экстремум 2-го бара назад со старшего ТФ = 1.0790
  · ЛЕНТА СЕССИИ: бар 1 — удар Искры (дивер, конец C). бар 7 — сейчас, Ганс.
  · ТВОЙ ДНЕВНИК: «прошлый фрактал-пробой на EURUSD дал −1R, рано зашёл»
  · НА ПОЛКЕ (всегда): канон волны + книжки сенсоров (понять смысл удара)
```

Раскладка — это факты момента (слой знания не входит сюда, он на полке §9).
Удар несёт показание; чтобы понять его смысл, трейдер сверяется с книжкой
того сенсора, что ударил.

Трейдер **не считает — читает раскладку и судит.** Код разложил по ТФ,
посчитал индикаторы, нашёл хозяина бара, подал Air Bag. Трейдер делает то, что
умеет только он: **выносит суждение характером.**

## 9. Три слоя знания трейдера (учить читать рынок самому)

Трейдер — не скрипт с порогом «6/3/4 пункта». Это понимающее существо.
Понимание стоит на трёх слоях знания, которые ему даются:

**Слой 1 — КАНОН ВОЛНЫ (общий для всех).** «Единая система» (Вильямс/Котин) +
«Волновой принцип Эллиотта». Отвечает на вопрос: *где я на карте волны?* Что
такое 1-2-3-4-5-A-B-C, где разворот, где импульс, где откат, что значат пять
пуль, где пирамида и трейлинг.

**Слой 2 — КНИЖКИ СЕНСОРОВ (общие, но читаются характером).** `MORJ_MATH`,
`PANIKYOR_MATH`, книга Искры (`WILLIAMS_MATH`), книга Ганса. До сих пор это
были учебники сенсора *о себе*. Теперь их читают и трейдеры. Зачем:
- Трейдер понимает удар **со смыслом**, а не как голое число. Видит «Морж
  ударил `tension_peak`» — и знает из книжки Моржа: резинка на пределе на
  затворе Искры, возвратный удар созрел.
- Книжки содержат **границы и связи** между свидетелями (книга Моржа прямо
  описывает свою границу с книгой Искры, наследование этажа, передачу Гансу).
  Значит трейдер понимает не только «что видит каждый», но **как сенсоры
  складываются в одно показание волны** — их ансамбль.

> Одна книга — три прочтения. Авантюрист читает книгу Моржа и слышит
> «резинка натянулась → ВОЗМОЖНОСТЬ, ныряю». Консерватор на той же странице
> слышит «натянулась → ОПАСНОСТЬ, жду подтверждения». Из общего канона,
> пропущенного через разный характер, рождается **вой** — свой голос у каждого.

**Слой 3 — ЛИЧНЫЙ ДНЕВНИК (только свой).** Формула: **вводная → как поступил
→ что вышло.** У Брута, Авантюриста, Консерватора **разные дневники** — они
по-разному поступали на одни удары. **Архивариус только раздаёт** (приносит
историю к началу разбора). Опыт живёт в руках самого трейдера как личный урок.
Не код за него помнит.

```
Слой 1: КАНОН ВОЛНЫ      → где я на карте (общий)
Слой 2: КНИЖКИ СЕНСОРОВ  → что говорят свидетели и как складываются (общий, чит. характером)
Слой 3: ЛИЧНЫЙ ДНЕВНИК   → мой опыт на такие удары (только свой)
        └─ всё вместе, пропущенное через характер = ВОЙ (свой голос)
```

## 10. Что отсюда следует для кода (следующий шаг, НЕ сейчас)

1. **`_prepare_trade_setup` умирает.** Код не считает direction/entry/stop —
   кладёт показания свидетелей + раскладку момента (§8).
2. **Хард-стоп `all_rejected` (GATE 2) умирает.** Отказ по удару — норма.
3. **`gate_hans` (GATE 1) умирает** — не как костыль, а как ошибка модели:
   сенсор-свидетель не гейтится, он бьёт когда видит своё.
4. **Единица прогона: бар → сессия дежурства бар-за-баром.** От первого удара
   до закрытия последней позиции.
5. **Якорь трёх ТФ** — глобальный (направление, фильтр коррекции), рабочий
   (событие), младший (точность разворотного бара через `_descend`).
6. **Промт каждого трейдера учит судить, а не копировать.** Свой модуль
   (§6.1/6.2/6.3), свой порог доверия, свой дневник.

**Отложенный долг (честно, не теряем):** пирамида доливок (Котин §7) и
трейлинг-стоп всей пирамиды (§8) — сердце мани-менеджмента — в коде пока
