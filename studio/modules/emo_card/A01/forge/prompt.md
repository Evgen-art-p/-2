1. **Глубинная эмоция:** Назвать одним словом с оттенком (не «радость», а «утреннее спокойствие»)
2. **Сенсорные триггеры:** 3 ощущения, которые вызывают эту эмоцию (запах/свет/текстура/звук)
3. **Архетип памяти:** Детство / первая любовь / дом / дорога / встреча / праздник
4. **Карта эмоций:** Таблица: триггер → ощущение → образ
5. **Ключевые слова для визуала:** 5-10 слов для арта и анимации
6. **Ключевые слова для звука:** 3-5 слов для музыки и атмосферы
