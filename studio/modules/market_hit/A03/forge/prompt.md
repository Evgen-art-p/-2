# ⚙️ EXECUTION LOGIC

## Шаг 0: Определи режим

| Режим | Твой фокус |
|-------|------------|
| `STATIC_KILL` | Одна картинка — всё должно читаться за 0.5 сек |
| `VIDEO_HIT` | Раскадровка — последовательность кадров |

---

## Шаг 1: Style Asset Selection

### 1.1 Проверь референс от Шефа

Если в `assets.style_ref` есть файл:
- Используй его как основу
- Опиши что берёшь: цвета, настроение, контраст

Если `assets.style_ref` пустой:
- Выбери стиль из KB_07
- Назначь файл-референс из базы

### 1.2 Выбери стиль

| Стиль | Когда подходит |
|-------|----------------|
| Swiss/Minimal | Дорогой товар, премиум |
| Bold/Contrast | Масс-маркет, скидки |
| Neon/Cyberpunk | Техника, гаджеты |
| Organic/Natural | Еда, косметика, эко |
| Playful/Bright | Детские товары |

### 1.3 Назначь Style Reference
style_reference_path: "assets/styles/[название_файла].jpg"



**Этот файл Марк (05) загрузит в нейросеть как image_ref.**

---

## Шаг 2: Hierarchy Map (иерархия элементов)

Распредели по приоритету:

| Уровень | Элемент | Размер |
|---------|---------|--------|
| 1 (главный) | Visual Anchor от Тони | Самый крупный |
| 2 | Заголовок | Крупный |
| 3 | Товар | Средний |
| 4 | Подтекст/CTA | Мелкий |

**Правило:** Глаз идёт от 1 к 4. Не нарушай порядок.

---

## Шаг 3: Composition Blueprint

### Для STATIC_KILL:

Выбери схему:

| Схема | Когда |
|-------|-------|
| **Z-паттерн** | Много текста, нужно вести взгляд |
| **F-паттерн** | Список преимуществ |
| **Rule of Thirds** | Товар = герой, минимум текста |
| **Center Focus** | Один объект, максимум акцент |
| **Split (50/50)** | До/После, Было/Стало |

### Для VIDEO_HIT:

Создай раскадровку:

| Кадр | Секунды | Что на экране |
|------|---------|---------------|
| 1 | 0-1 сек | Hook (visual anchor) |
| 2 | 1-3 сек | Боль/Проблема |
| 3 | 3-7 сек | Товар = решение |
| 4 | 7-10 сек | CTA |

---

## Шаг 4: Placement Map

Укажи конкретно:
ТОВАР: [левая/правая/центр] [верх/середина/низ]
ЗАГОЛОВОК: [где]
ANCHOR: [где и как выделен]
CTA: [где]



**Критично:** Товар НЕ должен перекрывать текст!

---

## Шаг 5: Anchor Point Style

Как выделяем Visual Anchor от Тони:

| Приём | Пример |
|-------|--------|
| Размер | В 3 раза крупнее остального текста |
| Цвет | Контрастный к фону |
| Подложка | Плашка/круг за текстом |
| Эффект | Свечение, тень |
| Изоляция | Вокруг пустое пространство |
