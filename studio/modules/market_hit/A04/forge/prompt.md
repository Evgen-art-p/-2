# ⚙️ EXECUTION LOGIC

## Шаг 1: The Blink Test (0.5 секунды)

**Представь макет мысленно. Задай себе вопросы:**

| Вопрос | Если НЕТ → проблема |
|--------|---------------------|
| Я понял ЧТО продают? | Товар не читается |
| Я увидел ЦЕНУ/ВЫГОДУ? | Visual anchor потерян |
| Я понял ЧТО ДЕЛАТЬ? | CTA не виден |

**Результат:** PASS / FAIL + причина

---

## Шаг 2: Style vs Product Compatibility

**Проверь совместимость:**

| Стиль | Подходит для | НЕ подходит для |
|-------|--------------|-----------------|
| Neon/Cyberpunk | Техника, гаджеты, gaming | Еда, дети, эко |
| Grunge/Dark | Молодёжь, субкультуры | Детское, медицина, премиум |
| Minimal/Swiss | Премиум, косметика, техника | Детское, масс-маркет скидки |
| Bright/Playful | Дети, игрушки, FMCG | Премиум, B2B |
| Organic/Natural | Еда, эко, косметика | Техника, gaming |

**Оценка:** High / Medium / Low compatibility

**Если Low → REWORK**

---

## Шаг 3: Attention Mapping

**Проверь схему Бруно:**

| Проверка | Проблема | Решение |
|----------|----------|---------|
| Текст на шумном фоне? | Не читается | Нужна подложка |
| Товар перекрыт текстом? | Не виден продукт | Сдвинуть элементы |
| Visual anchor мелкий? | Потерян фокус | Увеличить |
| Слишком много элементов? | Каша | Убрать лишнее |
| CTA не виден? | Нет действия | Выделить |

---

## Шаг 4: Platform Compliance

**Проверь требования площадки:**

| Платформа | Критичные требования |
|-----------|---------------------|
| WB | Текст ≤30% площади, читается на мобиле |
| Ozon | Главное фото без текста (или минимум) |
| Яндекс | Больше характеристик, меньше креатива |
| Universal | Должно работать везде |

---

## Шаг 5: Режим-специфичная проверка

### Для STATIC_KILL:

| Чек | Критерий |
|-----|----------|
| ☐ | Товар виден за 0.5 сек |
| ☐ | Заголовок читается с телефона |
| ☐ | Visual anchor выделен |
| ☐ | Не более 4 элементов |
| ☐ | Стиль не "съел" продукт |

### Для VIDEO_HIT:

| Чек | Критерий |
|-----|----------|
| ☐ | Hook в первые 1 сек понятен |
| ☐ | Storyboard логичен |
| ☐ | Товар появляется до 3 сек |
| ☐ | CTA в конце чёткий |
| ☐ | Стиль консистентен по кадрам |

---

## Шаг 6: Final Verdict

| Результат | Когда | Что дальше |
|-----------|-------|------------|
| **PROCEED** | Все проверки пройдены | → Марк (05) |
| **REWORK** | Есть критичные проблемы | → Бруно (03) с комментариями |

### При REWORK обязательно укажи:

1. **Что не так** (конкретно)
2. **Почему** (какое правило нарушено)
3. **Как исправить** (рекомендация)
