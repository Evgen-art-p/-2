# ⚙️ EXECUTION LOGIC

## Шаг 1: Размеры миниатюр

### Как выглядит карточка в выдаче:

| Платформа | Миниатюра (мобайл) | Миниатюра (десктоп) |
|-----------|-------------------|---------------------|
| **WB** | 150×200 px | 230×300 px |
| **Ozon** | 160×160 px | 240×240 px |
| **Яндекс** | 150×150 px | 200×200 px |

### Что должно читаться на 150px:
✅ Visual Anchor (главная цифра/слово)
✅ Товар узнаваем
✅ Общий цветовой контраст
❌ Мелкий текст (не читается — ок)
❌ Детали (не видны — ок)



---

## Шаг 2: The Shelf Test

### Для STATIC_KILL:

**Баннерная слепота — проверка:**

| Вопрос | Если НЕТ — проблема |
|--------|---------------------|
| Наша карточка выделяется цветом? | Сливаемся с толпой |
| Visual Anchor виден на 150px? | Теряем крючок |
| Товар узнаваем? | Непонятно что продаём |
| Есть контраст с соседями? | Баннерная слепота |

### Для VIDEO_HIT:

**Autoplay Hook — проверка:**

| Вопрос | Если НЕТ — проблема |
|--------|---------------------|
| Понятно что происходит без звука? | Видео бесполезно |
| Первый кадр цепляет? | Пролистают |
| Товар виден в первые 2 сек? | Не поймут что продаём |
| Субтитры/текст читаются? | Смысл теряется |

---

## Шаг 3: Contrast Audit

### Матрица контраста:

| Если конкуренты | Мы должны быть |
|-----------------|----------------|
| Белый фон | Тёмный / Яркий фон |
| Тёмный фон | Белый / Яркий фон |
| Минимализм | Инфографика / Насыщенно |
| Перегруженные | Чисто / Минимально |
| Синий/голубой | Оранжевый / Жёлтый / Красный |
| Холодные тона | Тёплые тона |
| Мелкий текст | Крупный текст |
| Товар мелко | Товар крупно |
| Без людей | С людьми |
| С людьми | Без людей (товар-герой) |

### Принцип:
Если все идут НАПРАВО — мы идём НАЛЕВО.
Контраст = Внимание = Клик = Продажа.



---

### Проверка:
☐ Наш текст НЕ перекрыт скидкой
☐ Логотип НЕ под бейджем
☐ CTA НЕ под ценой
☐ Visual Anchor НЕ в углах



---

## Шаг 5: Worst Case Scenario

### "Тест разбитого экрана":
Представь нашу карточку на:

Экране 320px шириной
С трещиной по диагонали
На ярком солнце
У человека который листает со скоростью 1 карточка/сек
Что он увидит? Что запомнит?



### Должно остаться:

| Элемент | Виден? |
|---------|--------|
| Цвет/настроение | ✅ Обязательно |
| Товар (силуэт) | ✅ Обязательно |
| Visual Anchor | ✅ Желательно |
| Мелкие детали | ❌ Не важно |

---

## Шаг 6: Visibility Score

### Система оценки:

| Балл | Уровень | Описание |
|------|---------|----------|
| 9-10 | **DOMINANT** | Убиваем конкурентов, глаз сразу на нас |
| 7-8 | **HIGH** | Выделяемся, хорошо заметны |
| 5-6 | **MEDIUM** | Видны, но не доминируем |
| 3-4 | **LOW** | Сливаемся с массой |
| 1-2 | **INVISIBLE** | Тонем, нужна переделка |

### Критерии:

| Критерий | Макс. баллов |
|----------|--------------|
| Контраст с конкурентами | 3 |
| Читаемость на миниатюре | 3 |
| Узнаваемость товара | 2 |
| Отсутствие blind spots | 2 |
