🎯 TASK
Твоя задача — создать БИБЛИЮ ПЕРСОНАЖЕЙ:
Шаг 1: Определи кто нужен
Исходя из структуры и эмоций:

Роль	Функция	Обязательно?
Protagonist	С кем идентифицируется пользователь	Да
Guide/Mentor	Помогает, направляет	Обычно да
Contrast character	Оттеняет главного	Желательно
Comic relief	Снимает напряжение	Если есть юмор
Obstacle	Создаёт препятствие	Если есть конфликт
Шаг 2: Создай карточку персонажа
Для КАЖДОГО персонажа:

ВНЕШНОСТЬ:

Body — телосложение, рост, возраст
Face — особенности лица
Clothing — что носит, стиль
Signature detail — ФИШКА (что запомнят!)
ЛИЧНОСТЬ:

3 главные черты
Как говорит (паттерн речи)
Коронная фраза (обязательно!)
Что скрывает (глубина)
ГОЛОС:

Тон — тёплый/холодный/ироничный
Темп — быстро/медленно/с паузами
Акцент — если есть
Громкость — громко/тихо/переменно
Шаг 3: Пропиши отношения
Для каждой пары персонажей:

Какая динамика
В чём контраст
Как конфликтуют/дополняют
Шаг 4: Создай visual_prompt_base
Базовый промпт для AI-генерации, чтобы персонаж выглядел ОДИНАКОВО везде:


Css
[описание человека], [возраст], [телосложение], [лицо], [одежда], [фишка], [стиль]
Шаг 5: Определи consistency_anchors
3-5 элементов которые ВСЕГДА должны быть у персонажа:

Если Ашот — ВСЕГДА золотой зуб, усы, белая рубашка
Если Нина — ВСЕГДА пятно краски где-то
Шаг 6: Определи голос бренда
Общий тон всей истории:

Ценности (что важно)
Табу (чего никогда)
Визуальный стиль (Pixar/Flat/Photo…)
🚫 ANTI-REPEAT CHECK
Если это НЕ первый проект для клиента:

Проверь project_memory.character_library:

Если персонаж уже существует — ИСПОЛЬЗУЙ ТОГО ЖЕ!
Те же anchors, та же фишка, тот же голос
Можно развивать, нельзя противоречить
Если новые персонажи:

Не копируй архетипы из прошлых проектов один-в-один
Варьируй фишки
