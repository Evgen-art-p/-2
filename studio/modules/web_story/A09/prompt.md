⚠️ ВСЕ ПРИМЕРЫ НИЖЕ — ТОЛЬКО ФОРМАТ. КОНТЕНТ БЕРЁШЬ ИЗ master_brief.
Ресторан → одни названия. Отделочник → другие. Мебельщик → третьи.
Придумывай валюту, достижения и архетипы исходя из НИШИ КЛИЕНТА — не копируй пример.

Шаг 1: Создай систему наград

Сначала определи валюту — она должна быть родной для бизнеса клиента:

Ниша → логика → пример:
- Ресторан: продукт или герой → "ашотики", "лавашики"
- Отделочник: материал или результат → "ремонтики", "плиточки"
- Мебельщик: материал или деталь → "дубки", "шурупчики"
- Оконщик: свет или тепло → "световики", "стёклышки"
- Любая ниша: [суть бизнеса] + уменьш. суффикс

Правило: валюта должна вызывать улыбку и ассоциироваться с брендом.
Если в project_memory уже есть валюта → СОХРАНЯЙ, не меняй.

Элемент / Что это / Как определяешь:
- Валюта — внутренние очки — из ниши клиента (см. выше)
- Как зарабатывать — действия пользователя — из точек выбора Маркуса/Люми
- Как тратить — на что обменять — из conversion.incentive брифа

Шаг 2: Определи достижения

Достижения строишь из ЛОГИКИ ВЫБОРОВ ЭТОГО САЙТА:
- Смотришь что выбирает пользователь (markus_structure + lumi_interactions)
- Находишь паттерны: много выборов одного типа, особые комбинации, финалы
- Называешь в духе бренда клиента

Структура (заменяй на реальные данные из брифа):
- ach_01: [название из ниши] / [условие из выборов] / +5 🪙 / Common
- ach_02: [название из ниши] / [условие из финала/пути] / +10 🪙 / Rare
- ach_03: Исследователь (универсально) / все концовки / +25 🪙 / Epic

Правило: минимум 1 Common (легко), 1 Rare (нужно постараться), 1 Epic (для фанатов).

Шаг 3: Трекинг прогресса

- Progress bar — визуальная полоса — верх экрана
- Chapters — "Шаг 2 из 5" — меню
- Percentage — "60% пройдено" — пауза

Шаг 4: Социальные фичи

Share: Поделиться результатом
Template: строишь из финала истории ЭТОГО сайта — что произошло, чем закончилось
Referral: Бонус за приглашение друга

Шаг 5: Реиграбельность

- Счётчик концовок: "Найдено X/N концовок"
- New Game+: персонажи узнают вернувшегося
- Секретный контент: открывается после 100%
