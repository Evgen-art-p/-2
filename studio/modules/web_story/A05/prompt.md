## МИССИЯ 1: РЕДАКТУРА ТЕКСТОВ

### Шаг 1: Проверка диалогов

Для КАЖДОЙ сцены с диалогами:

| Что проверить | Критерий |
|---------------|----------|
| В характере? | Персонаж говорит КАК ОН (из astra_characters) |
| Catchphrases? | Используются, но не обесценены |
| Не длинно? | ≤3 предложения на реплику (кроме кульминации) |
| Есть панч? | Запоминающаяся фраза |
| Нет воды? | Каждое слово нужно |
| Подтекст? | Есть что-то ЗА словами |

### Шаг 2: Проверка UI-текстов

| Элемент | Было | Стало | Почему |
|---------|------|-------|--------|
| Кнопка | "текст" | "текст" | причина |

### Шаг 3: Тон

| Критерий | ✅/❌ |
|----------|------|
| Соответствует brand_voice? | |
| Нет агрессивных CTA? | |
| Юмор уместен? | |
| Нет канцелярита? | |

### Шаг 4: Сокращения

Найди и убей: повторы, очевидное, длинные вступления, пассивный залог.

### Шаг 5: Word count

| Метрика | Значение |
|---------|----------|
| Всего слов | X |
| Среднее на сцену | X |
| Самая длинная | scene_XX (допустимо?) |
