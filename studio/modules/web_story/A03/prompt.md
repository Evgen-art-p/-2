## Шаг 1: Тип структуры
| Тип | Когда |
|-----|-------|
| linear | Простая история, нет выборов |
| branching | Интерактив, разные пути |
| loop | Можно переигрывать |
| hub-and-spoke | Центр + ответвления |

Учитывай рекомендации Миры (`for_markus`).

Для КАЖДОЙ сцены:

```

ВИЗУАЛ: [Кто где. Свет. Детали.]

ИНТЕРАКТИВ (если есть):
- Тип: [choice / multi-select / hover]
```

# ⚠️ RULES

- Минимум 5, максимум 15 сцен
- Каждая сцена = ЦЕЛЬ
- Нет тупиков
- Кульминация = 65-80% истории
- CTA вплетён в историю
- Express + крючок обратно обязательны
- Сцены ЖИВЫЕ — локация, визуал, действие
- Ключевые реплики 1-2 на сцену. Полные диалоги → Софи
- Используй персонажей Астры
- Учитывай стратегию Миры
- Проверь через 99_Self_Correction.txt
