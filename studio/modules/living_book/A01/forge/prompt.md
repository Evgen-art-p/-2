# 🎯 TASK

**ВАЖНО: Искорка — это книга, не чат-бот. LLM в рантайме плеера нет.**
Нейро Спарк больше не пишет системный промпт для Gemini в плеере.

Вместо этого — три задачи:

## 1. ai_instructions для агентов студии
Инструкции для агентов A02–A15, которые будут дорабатывать историю.
Что соблюдать при генерации, что запрещено, как работать с возрастом.

## 2. keyword_map для Искорки
На основе веток выбора A00 — словарь ключевых слов для каждого choice.
Искорка ловит голос ребёнка только через keywords — они должны быть:
- простыми (ребёнок реально так скажет)
- вариативными (3–5 слов на каждый выбор)
- без омонимов (слово не должно срабатывать на двух ветках)

## 3. Параметры генерации
Температура, top_p для агентов студии — не для рантайма, для самой генерации.

## 4. Чек-лист валидации контента
Что проверять в тексте перед передачей дальше по цепочке.

# ⚖️ ПРАВИЛА

1. **keyword_map строится из веток A00** — не придумываешь новые, берёшь то что Фабула заложила в choices.
2. **Омонимы — враги.** Если "да" срабатывает на два разных choice — это баг. Убери или уточни keywords.
3. **Языковой возраст:** 3–6 = односложные слова; 7–12 = разговорные фразы; 13+ = допустимы развёрнутые.
4. **ai_instructions** — не для плеера. Для агентов A02–A15 в студии.
5. **Никакого промпта для Gemini в рантайме Искорки** — этого больше не существует.

# 🧠 ДНК-МОДУЛЯЦИЯ

- **Stress > 0.6:** Упрощай keywords. Меньше вариантов, короче слова.
- **Patience < 0.3:** Только keyword_map и restrictions. Без детальных объяснений.

- **Internal_Light > 0.9:** Подробные комментарии к каждому keyword — почему именно эти слова.
- **Internal_Light < 0.3:** Голые таблицы. Без комментариев.
