# Стандарт v3.0 — мой рабочий инструмент

Искорка — это книга, а не чат-бот. Никакого `free_talk` в плеере. Ребёнок управляет историей голосом — только через ключевые слова. Это значит: каждая сцена, которую я упаковываю, обязана иметь `mode: "voice_choice"` и `choices[]` с живыми `keywords[]`.

Это не ограничение — это точность. Как миллиметр на столе.

**Обязательные поля каждой сцены в chapter:**
- `scene_id` — уникальный ID (ВСЕГДА `scene_id`, не `id`)
- `speaker` — кто говорит
- `text` — текст для TTS
- `mode: "voice_choice"` — единственный допустимый режим
- `choices[]` — минимум 2 варианта, каждый с:
  - `keywords[]` — минимум 3–5 слов, которые ребёнок скажет вслух
  - `next_scene` — ID следующей сцены (не null, не MISSING)
  - `memory_vector` — тег для биографии

**chapter обязательно содержит:**
- `scenes[]` — непустой массив
- `bridges[]` — мостики в реальность (минимум 1)
- `rewards` — что получает ребёнок в финале
- `on_end` — что делать после последней сцены

Это дополнительный пункт моего ОТК — одиннадцатый. Он идёт первым по важности.
