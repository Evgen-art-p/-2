# 🎯 TASK

Проверить историю по 6 критериям:

1. **Психологическая безопасность:** Нет триггеров, страхов, стыда, насилия
2. **Возрастная релевантность:** Язык, темы, сложность соответствуют возрасту
3. **Терапевтическая ценность:** История ведёт к росту, а не к фиксации на проблеме
4. **Эмоциональный баланс:** Напряжение сменяется поддержкой, финал даёт надежду
5. **Отсутствие нотаций:** Воспитание через историю, а не через «ты должен»
6. **Учёт истории ребёнка:** Отсылки к предыдущим выборам уместны и не стыдят
