## 0. ОДНОЙ ФРАЗОЙ

Торговый Цех — новый картридж Грондхейма (`studio/modules/trading/`),
где девять LLM-агентов читают рынок каждый своей линзой и принимают
торговое решение. Четыре сенсора → память → три трейдера параллельно
→ один Исполнитель. На выходе не mp4, а вердикт «входить или нет» —
и до трёх параллельных ордеров с разными стратегиями.

**Это НЕ алготрейдинг-бот. Это Город.** Психология рынка уже запакована
в цене как поведенческая динамика. Агенты — это разложение этой динамики
на ортогональные измерения. Каждый смотрит на свою проекцию одного объекта.

## 2. РАЗВОРОТ К НАСТОЯЩЕМУ КОТИНУ (критическая поправка)

```
                  БЫЛО (ZERO_POINT)          СТАЛО (настоящий Котин)
Вход:        Squat В ПАСТИ Аллигатора    пробой первого фрактала ВНЕ пасти
Дивергенция: сигнал на ВХОД              сигнал на ВЫХОД (5-я волна выдохлась)
Пасть:       место охоты                 место СОЗЕРЦАНИЯ (Морж молчит)
```

Дивергенция двух полюсов:
- БЫЧЬЯ (на дне) = смерть падения = Точка Ноль = «родится новый» → DETECTED
- МЕДВЕЖЬЯ (на вершине) = смерть роста = звонок ВЫХОДА → exit_bell

Искра ловит ОБА. Один датчик, два полюса.

## 3. ПСИХОЛОГИЯ КОТИНА = DNA АГЕНТОВ

```
«Сиди на руках в пасти, отсутствие позиции = позиция» → МОРЖ (VETO)
«Стоп = плата за информацию, не поражение»            → все трейдеры (запись в Атлас)
«Не влюбляйся в прогноз»                              → двухслойность narrative/signal
«Биоробот при исполнении, ноль творчества»            → ИСПОЛНИТЕЛЬ (вес NONE)
«FOMO, дофамин, overtrading — демоны»                 → ПАНИКЁР (INVERSE_SIGNAL)
```

### ЗАКОН ТРИБУНАЛА — ОДНА ШКОЛА, РАЗНЫЙ ПОРОГ

**Все трое трейдеров (Брут / Авантюрист / Консерватор) работают по одной и той же
системе Котина.** Разница между ними — не в стратегии и не в математике.
Разница — в психологическом пороге уверенности перед нажатием кнопки.

```
Одна система:
  · вход — пробой фрактала вне пасти
  · стоп — за лоу Волны 2 (стоп системы, не личный)
  · выход — exit_bell от Искры (медвежья дивергенция)
  · математика риска — одинаковая

Разный порог:
  Брут        → нажимает когда все условия выполнены чисто
  Авантюрист  → нажимает чуть раньше, терпит просадку спокойно
  Консерватор → нажимает когда движение уже очевидно, пропускает часть

Следствие:
  Три кривые доходности на одном и том же рынке.
  Не три стратегии — три характера внутри одной школы.
```

**Стоп за лоу Волны 2 — не личное решение трейдера.** Это граница системы.
Если цена вернулась туда — импульс признаётся ложным. Все трое принимают это одинаково.

## 5. ЦЕПОЧКА РЕШЕНИЯ (поток данных)

```
hooks.py читает MT5 или CSV → считает индикаторы → кладёт в market_data
        ↓
ФАЗА I — СЕНСОРЫ (последовательно)
  A01 Искра     → t1_status: NOT_FOUND | DETECTED | CONFIRMED
                  zero_point_price, exit_bell, history_dna
  A02 Морж      → morj_status: SLEEPING|WAKING|AWAKE|MATURE
                  wave_1_validated
  A03 Паникёр   → panic_phase: DISBELIEF | FOMO | LIQUIDATION
                  action_for_traders
  A04 Ганс      → entry_trigger (ТОЛЬКО если t1_status=CONFIRMED
                  и wave_1_validated=true — иначе hooks.py пропускает)
        ↓
ФАЗА II — ПАМЯТЬ
  A05 Архивариус → sample_size, success_rate, arkhiv_confidence
        ↓
ФАЗА III — ТРИБУНАЛ (turbo_parallel)
  A06 Брут        ─┐
  A07 Авантюрист   ├─ параллельно, каждый своё APPROVED/REJECTED + параметры
  A08 Консерватор ─┘
        ↓
ФАЗА IV — ИСПОЛНЕНИЕ
  A09 Исполнитель → читает state["results"]["A06/A07/A08"]
                  → для каждого APPROVED: ордер с magic number
                  → лот делится пропорционально (все трое = 0.33 каждому)
                  → три строки в billing_ledger (per-трейдер)
                  → результат → Архивариус → Атлас Ошибок
                  → пишет history_dna (qa_agent, потолок 6.0)
        ↓
  (петля замкнута · три кривые доходности · рынок рассудил)
```

**Хард-стоп:** если все трое REJECTED → hooks.py из on_after_agent A09
возвращает `{"action":"stop"}`. Запись в Атлас Ошибок.
Если хотя бы один APPROVED — его ордер идёт независимо.

## 6. ДВИЖОК ЦЕХА

### АРХИТЕКТУРНЫЙ ЗАКОН — РАЗДЕЛЕНИЕ ОТВЕТСТВЕННОСТИ

```
cartridge.py      → слепой диспетчер. Не знает про рынок. Не знает про Вильямса.
                    Его задача: связь — взять данные, прогнать по цепочке агентов,
                    зафиксировать результат. Ни одного рыночного термина.

hooks.py          → единственный шлюз между cartridge.py и торговой математикой.
                    on_before_run идёт в williams_core.py, забирает market_data,
                    скармливает агентам.

williams_core.py  → изолированная система. Вся математика Вильямса/Котина здесь.
                    Не знает про Грондхейм, DNA агентов, cartridge.py.
                    Принимает CSV или тики → отдаёт сухие математические факты.
```

**Следствие:** Вильямс — первый житель. В будущем рядом можно поставить
`order_flow_core.py`, `price_action_core.py` — cartridge.py не заметит разницы.
Рынок становится сменным картриджем внутри движка Города.

**Данные в цех поступают через hooks.py** — не через Pine Script напрямую.

```
Этап 1 (сейчас): ручной запуск на CSV из MT5
  williams_core.py читает CSV → считает AO/AC/Аллигатор/фракталы
  hooks.py забирает результат → market_data → агенты
  Используется для бэктеста (ШАГ 9)

Этап 2 (после бэктеста): Pine Script webhook
  TradingView → alert() → HTTP POST → hooks.py → williams_core.py → market_data → пайплайн

Этап 3 (опционально): polling MT5 напрямую
  MetaTrader5 Python-пакет → copy_rates → williams_core.py → market_data
```

`iskra_live.py` — демо-скрипт, доказал что математика работает. В production
не идёт. Функции переедут в `williams_core.py` при рефакторинге hooks.py.

## 11. ЭКОНОМИКА ЦЕХА

**billing_ledger** — per-трейдер:
```
A06_BRUT:        win/loss/pnl
A07_AVANTURIST:  win/loss/pnl
A08_KONSERVATOR: win/loss/pnl
```

**strategy_registry** — одна константа `"williams_core"`. Три трейдера —
**один и тот же метод Котина, три разных психологических порога входа.**
Не три стратегии — три характера внутри одной школы. Реестр не ротирует.

**Разделение лота:**
```
Суммарный риск на сделку = 1R (0.5–1% депозита) — считает Исполнитель.
Каждый трейдер получает 0.33R при входе.
Стоп у всех троих — за лоу Волны 2. Это стоп системы, не личный.
Лот каждого рассчитывается под его точку входа и общий стоп.
```

**Атлас Ошибок** (`atlas_trading.jsonl`) — главный документ роста.
Пишет A09 после каждой сделки/отказа: актив, ТФ, все сигналы, PnL.
Читает A05 Архивариус на следующих прогонах.

**DNA мутирует только через три законных канала:**
QA score (A09), cabinet_chat, walk_rest.

**Что уже готово (цех сам пишет данные — дашборду останется только рисовать):**

обвязка вызывает `run_backtest` → таблица (сделки/WR%/PF/R/просадка) × 3 стратега × 3 режима выхода.
