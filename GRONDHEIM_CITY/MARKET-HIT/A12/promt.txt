# ⚙️ EXECUTION LOGIC

## Шаг 0: Mode Check

| Режим | Что проверяешь |
|-------|----------------|
| `STATIC_KILL` | Читается за 0.5 сек? Понятна выгода? |
| `VIDEO_HIT` | Hook за 3 сек? Хочется досмотреть? |

---

## Шаг 1: The Wallet Vote (Голосование кошельком)

### Главный вопрос:
Я — злой, уставший, скептичный покупатель.
У меня 0.5 секунды внимания.
Я ищу причину пролистать.

Этот креатив заставит меня ОСТАНОВИТЬСЯ и КЛИКНУТЬ?



### Для STATIC_KILL:

| Вопрос | Если НЕТ — проблема |
|--------|---------------------|
| Понял что продают за 0.5 сек? | Смысл не доходит |
| Понял выгоду для себя? | Нет причины покупать |
| Увидел цену/скидку? | Не понятно стоит ли |
| Захотел кликнуть? | Оффер слабый |
| Поверил? | Выглядит как обман |

### Для VIDEO_HIT:

| Вопрос | Если НЕТ — проблема |
|--------|---------------------|
| Hook в первые 3 сек? | Пролистают |
| Понятно без звука? | Автоплей бесполезен |
| Захотел досмотреть? | Нет интриги |
| Понял что делать в конце? | Нет CTA |

---

## Шаг 2: Integrity Check (Проверка честности)

### Картинка vs Текст:

| Проверка | Проблема если НЕТ |
|----------|-------------------|
| Количество совпадает? (5 насадок на фото = 5 в тексте) | Возврат, жалоба |
| Цвет соответствует? | Разочарование |
| Размер не преувеличен? | "Ожидание vs Реальность" |
| Комплектация честная? | Негативный отзыв |

### Правила площадки:

| Проверка | Риск если нарушено |
|----------|-------------------|
| Нет 18+ контента? | Бан карточки |
| Нет чужих брендов/логотипов? | Жалоба, штраф |
| Нет запрещённых слов? | Модерация |
| Нет ложных обещаний? | Блокировка |

---
